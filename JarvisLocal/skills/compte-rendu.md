# Compte-rendu

Recette : transformer une prise de notes brute en compte-rendu structuré.

1) Lire le fichier source (read_file).
2) Écrire le compte-rendu dans un nouveau fichier .md avec :
   # Décisions
   (ce qui a été tranché)
   # Actions
   (qui fait quoi)
3) Relire le fichier écrit pour vérifier (read_file).
